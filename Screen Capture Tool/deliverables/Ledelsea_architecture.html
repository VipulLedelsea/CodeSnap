Code Capture — Architecture & Design

System architecture, a UML class diagram, and the end-to-end data flow for the screen-capture-to-verified-report pipeline (burst pHash capture + the in-process multi-agent team).

System architecture

Three entry points (the hotkey app, the CLI, and the web UI) share one engine (core/) and two analysis paths — the single-agent loop and the multi-agent team. All model calls go to the Anthropic Messages API; results are saved as report bundles and surfaced by the web UI.

How a frame travels from the screen through pHash de-duplication, background Haiku extraction and caching, the chosen analysis path, validation/fix, and finally the pending report bundle the web UI offers for download.
